# Pet Nova 🐾

Sitio web de Pet Nova — "Cuidamos lo que amas".

## Páginas
- `index.html` — Home / About Us / Functions
- `login.html` — Inicio de sesión
- `registro.html` — Registro de usuarios

## Publicar en GitHub Pages
1. Sube el contenido de este repositorio a GitHub (rama `main`).
2. Ve a **Settings → Pages**.
3. En *Source* elige **Deploy from a branch**, rama `main`, carpeta `/ (root)`.
4. Guarda. En 1–2 minutos estará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.
